## 关键判断：逐项取值

**单位与口径**：单位 $B，EPS 为非 GAAP（剔除 SBC），年份为日历年（AMD 财年＝日历年）。

| 项目 | 我的取值（Base） | 依据 |
|---|---|---|
| **CY27 整体** | EPS $16.0 | 管理层 2Q26 会上说 2027 年 DC 收入「远超翻倍」、服务器 CPU 增速 >70%，以此为锚 |
| **CY28 GPU** | **$63.8B** ＝ 4.5GW × $13.5B/GW ＋ $3B 其他 | 「每 GW GPU 收入」是我定的换算口径：按 2027 年 GPU 约 $44B ≈ 3–3.5GW 的对应关系反推，≈ $126–147 亿/GW，取 $135 亿，不含同一机柜里的 Venice CPU。已宣布的承诺有 14GW（OpenAI 6、Meta 6、Anthropic 2），但 ① Helios 机柜量产吃力；② Meta 大部分下单的是砍半规格；③ Rubin 会先上量。所以 CY28 当年只按交付 4.5GW 算 |
| **CY28 服务器 CPU** | **$40.8B**（+38%） | 渠道数据：AMD 服务器 ASP 环比 +7%，全年定价 +20%，Venice（2nm 新一代 EPYC）的产品结构会继续推高单价。但出货受产能约束——苏姿丰自己说「服务器 CPU 供应链很紧」。量、价都取中间 |
| **毛利率** | CY27 54.4%／CY28 55.4% | 2027 年 HBM 大幅涨价，AMD 没法全部转嫁给大客户；CFO 也承认 Instinct 毛利率「略低于公司平均」 |
| **营业费用** | CY27 +35%、CY28 +20% | 管理层表示今明两年 opex 各增约 35% |
| **SBC** | 按公司口径 | 不额外加回 |
| **股数（最关键的一项）** | CY28 **1,802M**（权证 +1.09 亿股，约 6%）；CY30 约 2,015M（约 14%） | 见下方「全面摊薄 EPS」 |

**「全面摊薄 EPS」的定义**：把 OpenAI 和 Meta 两份认股权证（各最多 1.6 亿股，行权价 $0.01）按 GW 交付进度计入股数后算出的 EPS。每交付 1GW，归属约 2,667 万股（1.6 亿股 ÷ 6GW）。例如 Base 档 CY28 年内平均已归属约 4.1GW，对应增加 1.09 亿股，EPS 因此被摊薄 6%。

**为什么股数是最关键的修正**：

- ① Meta 在 2026-02 也拿到了一份同样结构的权证（SEC 8-K），很容易只算 OpenAI 那一份。
- ② 两份权证最后一批的股价门槛都是 $600，**现价 $631 已经越过**。只要交付 GW，股票就会归属，股价门槛已不构成约束。
- ③ 交付越多、稀释越多。Bull 档 CY30 稀释约 16%。

**结果**：Base 档 CY28 全面摊薄 EPS **$22.8**（不含权证口径 $24.3）。管理层 2025-11 分析师日给的目标是「3–5 年 EPS 超过 $20」，Base 档在第 3 年（2028）达到，节奏吻合。

## 估值方法：为什么用 P/E、锚定 CY28

**主方法：CY28 全面摊薄非 GAAP EPS × 前瞻 P/E，得出 12 个月目标价。**

为什么选 P/E：

- 利润正在拐点期，FY26 到 FY28 EPS 要涨两倍。EV/Sales 这类收入倍数没法反映毛利率和费用率的变化。
- 自由现金流被机柜放量期的营运资金扭曲（应付账款半年 +83%）。
- 市场给 AI 半导体定价用的就是前瞻 P/E，NVDA、AVGO 都可以直接比。

为什么锚定 CY28，而不是 CY27 或 CY29：

- 12 个月目标价的时点是 2027 年 9 月。那时市场看的「未来 12 个月」约等于 2027Q4–2028Q3，基本就是 CY28。
- CY27 是 Helios 放量的过渡年，毛利率被摊薄、季度间波动大，用它做锚会把爬坡期的噪音当成常态。
- CY29/30 权证稀释和客户集中度的不确定性太大，只放进 DCF 用。
- 一定要用「全面摊薄」股数，否则 EPS 会被高估。

**倍数怎么定：**

| 档 | CY28 P/E | 依据 |
|---|---|---|
| Bear | **16x** | AMD 失去溢价，向 NVDA 现在的 16.5x（12 个月前瞻）靠拢；AMD 2024-12 的低点是 15x |
| Base | **25x** | 2023–2026Q1 前瞻 P/E 的上沿（15–25x）；比 NVDA 16.5x、AVGO 19x 高约 30–50%，理由是 CPU 业务的定价权和份额上升空间；DCF 指向 19.5x，所以不再往上加 |
| Bull | **30x** | 市场把 AMD 当成「第二个 AI 平台＋CPU 定价权」 |

**交叉检验一：分部估值（SOTP，Base CY28）＝ $528。** GPU 给 20x，CPU 给 28x。服务器 CPU 是 x86 双寡头，产能紧张，有定价权；GPU 是第二名，客户高度集中，订单带着权证返利，实测性能落后于 Rubin。营业费用按收入占比粗分摊，结果只作方向参考。

**交叉检验二：DCF ＝ $401/股（今天的价值）。**

- 设定：CY27–30 用情景数，CY31–35 增速线性回落到 4%，股权成本 11%（无风险利率 4.3% + β 1.55 × 4.5%）。

- 所以 25x 是 Base 档可以给的上限，不是保守取值。

## 小词典

- **GW（吉瓦）**：数据中心用电功率。业内用「部署多少 GW」衡量 AI 算力规模，1GW 约等于几十万颗 GPU 加配套设备。
- **Helios**：AMD 的整柜 AI 服务器，一柜含 72 颗 MI455X GPU 和 18 颗 Venice CPU，对标 NVIDIA 的 NVL72 机柜。
- **MI355X / MI450 / MI455X / MI500**：AMD Instinct AI GPU 的各代型号。MI455X 是 MI450 系列里放进 Helios 的主力型号。
- **HBM / HBM4**：高带宽内存，叠在 GPU 旁边的专用内存，AI 芯片成本里很大一块；HBM4 是最新一代。
- **CoWoS**：台积电的先进封装工艺，把 GPU 芯片和 HBM 封到一起，产能是 AI 芯片出货的瓶颈。
- **N2 / N3**：台积电 2 纳米、3 纳米制程。
- **ROCm / CUDA**：AMD 和 NVIDIA 各自的 GPU 软件栈。
- **SerDes / retimer**：芯片之间高速传数据的收发电路；信号走远了会衰减，需要加 retimer（中继芯片）来补。
- **InferenceX / AgentX**：SemiAnalysis 自己的推理实测基准，AgentX 专测智能体类负载。
- **Venice / EPYC**：EPYC 是 AMD 服务器 CPU 品牌，Venice 是 2nm 的新一代 EPYC。
